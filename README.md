# Данный репозиторий содержит мои первые html шаблоны и request для страницы "контакты"

## Содержание
- Папка css для корректной работы bootstrap
- app.py содержащий get/post запросы для страницы "контакты"
- 4 html шаблона
- Файлы зависимостей для poetry

## Использование
Данный проект можно использовать для проверки request запросов.
Весь функционал находиться в app.py.
Для запуска используйте команду ```python app.py```.
В терминале вы увидите ссылку на страницу "Контакты".
Вы можете перейти по ней для проверки GET запроса.
Заполните форму на странице для проверки POST запроса.
